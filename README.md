# Seattle Airbnb Data Analysis | Tableau Dashboard

## Project Overview

This project explores Seattle Airbnb listing data using Tableau to analyse pricing patterns, geographical distribution, and property characteristics.

The objective is to transform raw listing data into meaningful insights through data visualization and interactive dashboard development.

## Project Objectives

- Analyse average Airbnb listing prices across different ZIP codes.
- Explore yearly revenue trends.
- Compare average listing prices based on the number of bedrooms.
- Examine the distinct bedroom categories within the dataset.
- Develop an interactive dashboard to present the analysis in a clear and structured format.

## Tools & Technologies

- **Tableau** – Data visualization and dashboard development
- **CSV** – Dataset format
- **GitHub** – Project documentation and version control

## Analysis & Visualizations

### 1. Average Price by Zipcode
Created a geographical map to visualize the average Airbnb listing price across different ZIP codes in Seattle.

### 2. Revenue by Year
Developed a line chart to examine yearly revenue trends and identify changes over time.

### 3. Average Price by Bedrooms
Created a bar chart to compare average listing prices across different bedroom categories.

### 4. Distinct Count of Bedrooms
Explored the distinct number of bedroom categories available in the dataset.

### 5. Interactive Dashboard
Combined the visualizations into a single dashboard to provide a consolidated overview of Seattle Airbnb listings.
